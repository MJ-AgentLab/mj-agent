# 原生开发技能执行边界

政策正文：项目 `AGENTS.md`、`policies/ai-agent.md` §2/§4 与 `sdd/workflows/execution-loop.md`。本文件不认证授权，不是审批凭证。原生资产直接维护；技术使能、外部运行和宿主加载须实际证据。

## 路径、工具与方法

`repo:路径` 从目标 Git 工作树根解析；先固定 `git rev-parse --show-toplevel`，不从旧客户端回退。秘密路径仅标禁止边界，不读取或计算摘要。缺失工具/依赖标 `UNMET_DEPENDENCY`。

先发现实际工具，文件搜索使用符号工具或 rg，写入与命令用正常工具。Windows 删除/移动用同一 shell 原生操作，先核绝对目标与授权。TDD=失败断言→红态→最小修复→绿态；诊断=可证伪假设和单变量；评审=真实成果与期望；文档=真实实现→模板→反扫→校验。运行只取适用证据，SKIP 不计 PASS。

## 授权、决定与硬阻断

- 接受基线和执行授权分记。任务授权列允许动作、对象、环境、权限、副作用、资源与停止条件，目标/对象/环境/权限/风险未实质变化且未撤销时复用。普通 Plan、实现、测试、局部修复及兼容契约自主完成；技能调用不新增权限。
- 四类 runtime 面按实际语义分类，基线内安全保持可自主；数据范围、SQL 安全、业务口径、外发、breaking、接受标准/必要门禁、信任/权限/生产/供应链来源变化给具体影响方案并停在 `OWNER_APPROVAL_REQUIRED`。
- stage/commit、普通 push、PR 创建及 merge 可以具名列入任务授权；删除/权限变更及高风险不可逆动作独立列明。平台有效审核、部署授权、运行验证和 Owner 接受分别记录；Owner在聊天对实际成果/SHA作批准或接受决定；Agent依该真实决定以不同于作者/最后推送者的Owner身份执行平台审核，补推须重新取得有效决定/审核，批准与业务接受分记；App作者身份无admin/checks-write/bypass。
- 独立Agent先读取真实原生配置/守卫并复现负例，执行Agent随后仅经宿主正常机制启用本项目信任、核实际加载/canary；不改个人config、不扩大权限、不绕技术拒绝。不支持的步骤如实未验证。仅新建单仓mj-agent-delivery-executor App的私钥/短期token允许由受控后台创建、DPAPI保存、签名、注入和撤销；模型、聊天、日志不可见。现有应用/MCP/DB/个人秘密永不读取，该例外不扩大服务、权限或操作授权。项目 MCP 仅既有 GitHub、Playwright、Serena、memory×5；biz×5、ssh-manager 及其他来源服务永久禁入。
- biz 只走 `find_biz_context → list_biz_tables → describe_biz_table → execute_sql`、analyst 只读；没有链路停，禁 DB 客户端或 memory 替代。秘密不打开/打印/日志/传输，禁止让用户贴回聊天。
- 授权不解锁技术拒绝；保留原错、证据定位、未知标未知，返回 `BLOCKED_EXECUTION_ROUTE`。不换工具、编码、改写命令、修改权限/规则或建 receipt 绕过；独立已授权工作继续。

## 调用、委派与返回

独立调用完成请求范围后返回；委派记录协调者、目标/AC/决定位置、输入/范围/依赖/产物、真实 workspace/ref/SHA/比较基线、验收证据、授权/资源/停止条件及返回点。下游 Handoff 是输入建议；任务已授权完整闭环可继续，无需固定阶段重新批准。发布评论、issue 或回复仍须对应明确授权。

按可划分与并行收益选择 Agent；并行写使用独立 workspace 或明确文件归属，共享资源写由协调者排序。effort 在同模型真实支持档和预算内自主选择与升级并记录依据，不自动换模型或扩权限。核验者独立读真实成果、建立期望、复现，不以 Agent 人数或总结证明通过。

## 失败、目标变化与重入

危险动作前核绝对路径、branch tip/PR head、PID/start time/command、compose project/profile/-f、volume/对象。删除另核 Git 状态、未跟踪/忽略内容、必要备份、占用与目标/后代重解析点；秘密不取摘要。变化只停受影响项；普通代码迭代核实际版本但不自动失去任务授权。

阶段结束、集成前及交接时在现记录保存目标/AC/授权、版本工作区集成状态、证据位置、在途失败未知延期、下一步及停止条件。重入先读检查点并核现实，超时/未知先对账副作用，成功项不重做。失败不自动 force/删卷/重建/轮换；恢复先核备份真实可用。

输出含实际贡献、风险与决定、BDD/TDD、委派/effort、成果/逐AC/版本环境/复现、限制延期/风险恢复/待决定及返回点。候选集成、验证、交付、待接受、接受、部分、延期、失败和未知分别表述；completed 须基线满足、成果可用且 Owner 明确接受。
